- 인공지능학습 : 비지도학습(군집) vs 지도학습(DNN)

* DNN, 자연어처리, RNN, LSTM, Seq2Seq

- 스케일 조정(정규화, 표준화)하는 목적? 계산이 안정적으로 향상

- Sequential 모델 : 순차적 레이어 모델
	model = Sequential() 순차모델 / Model(inputs=XX, outputs=XX) 병렬모델

	- 이진분류(로지스틱 회귀분석) 출력층 : model.add(Dense(1, activation='sigmoid'))  
	- 다중분류 출력층 : model.add(Dense(units, activation='softmax'))

- 학습과정 설정
	- 손실함수 (다중분류 : categorical-crossentropy / sparse_categorical_crossentropy)
			(이진분류 : binary_crossentropy)
			(회귀분석 : mse)
	- 옵티마이저
	- metrics(평가지표) : accuracy(정확도), precision(정밀도), recall(재현율)
		accuracy(정확도) = (TN+TP) / 전체수(TN+FP_FN+TP) 맞춘 비율
		precision(정밀도) = TP / 예측을 1이라고 한 수 (FP+TP)
						예측값 1 기준으로
		recall(재현율=민감도) =  TP /실제가 1인 수(FN+TP)
						실제값 기준 실제값1을 맞춘 비율

- accuracy를 늘리기 위한 방법
	- 데이터 확보, 레이어(레이어층도 늘리고 units수도 늘리고..), 활성화함수 은닉층에는 주로 relu
	- optimizer(learning rate), epoch 등을 적당히 조정

- 과적합 방지를 위한 방법
	- 데이터 확보, 증강. Dropout, BatchNormalization, L2정규화(L2규제.가중치 정규화), 활성화함수 relu
- 모델 저장 : 딥러닝에서 모델 저장 : *.h5 또는 *.keras
		  머신러닝에서 모델 저장 : *.pkl

- RNN, LSTM : 시계열데이터 예측, 자연어생성(텍스트해석), 자연어감성분석, 작곡
